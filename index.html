STEP 01

Install Python 3

Most Ubuntu installations already include Python 3 — the first move is always to check before installing anything.

Check what's already there

check-python.sh
$ python3 --version
Python 3.12.3

If that printed a version number, Python itself is already there. If it printed command not found, the install step below will fix that too.

Update package lists and install the essentials

install-python.sh
$ sudo apt update
$ sudo apt install -y python3 python3-pip python3-venv python3-dev
What each package does — python3-pip installs Python's package manager, python3-venv lets you create isolated project environments (step 3), and python3-dev provides the headers some ML libraries need to compile.
STEP 02

Install & launch Jupyter Notebook

Jupyter Notebook gives you a browser-based, cell-by-cell interface — write a bit of code, run just that cell, see the result right underneath it. We'll install it with pip, inside the virtual environment we set up in the next step, then launch it and run a Hello World cell to confirm it works.

Order note — Jupyter installs cleanly with a single pip install, but on modern Ubuntu that command only works inside a virtual environment. Skim Step 3 below first if you haven't created ~/aiml-lab/venv yet, then come back here.

Install Jupyter Notebook

(venv) install-jupyter.sh
(venv) $ pip install notebook

Launch it

(venv) launch-jupyter.sh
(venv) $ jupyter notebook
Serving notebooks from local directory: ~/aiml-lab
http://localhost:8888/tree?token=...

This opens a new browser tab showing the file list for ~/aiml-lab. Leave this terminal window running in the background — closing it shuts the notebook server down. Click New → Python 3 in the top-right to create your first notebook.

Hello World, in a cell

Click into the first (empty) cell, type the line below, then press Shift + Enter to run it. The output appears directly underneath the cell — no separate terminal needed.

In [1]:
print("Hello, world!")
Hello, world!

Rename the notebook by clicking "Untitled" at the top of the page — try hello-world.ipynb — and it'll save into ~/aiml-lab alongside your venv folder.

STEP 03

Create a project and a virtual environment

A virtual environment keeps this course's packages separate from your system Python — and on modern Ubuntu, it's the difference between pip working and pip refusing to run.

create-venv.sh
$ mkdir -p ~/aiml-lab && cd ~/aiml-lab
$ python3 -m venv venv
$ source venv/bin/activate
(venv) student@ubuntu-lab:~/aiml-lab$

That (venv) prefix means the environment is active — any pip install from here goes into this project only, not your whole system. You'll run this source venv/bin/activate command every time you reopen a terminal for this course, including before launching Jupyter.

Why this matters — Newer Ubuntu releases (23.04+) block pip install outside a virtual environment with an externally-managed-environment error. Working inside venv sidesteps that entirely, so get in the habit now.
STEP 04

Install the core AI/ML packages

With the virtual environment active, install the libraries we'll use across the semester.

(venv) install-packages.sh
(venv) $ pip install --upgrade pip
(venv) $ pip install numpy pandas matplotlib scikit-learn notebook
  • numpy — arrays and numerical computing
  • pandas — tabular data and datasets
  • matplotlib — plotting and visualization
  • scikit-learn — classical ML models
  • notebook — Jupyter Notebook, already installed in Step 2, listed here so requirements.txt captures everything in one place

Save the list for next time

(venv) freeze.sh
(venv) $ pip freeze > requirements.txt

Anyone (including future-you) can then recreate this exact environment with pip install -r requirements.txt.

JUST IN CASE

Troubleshooting

The most common snags from past sessions, and the fix for each.

pip says "externally-managed-environment"
You tried to pip install outside a virtual environment. Run source venv/bin/activate first (Step 3), then install again.
"command not found: pip3" right after installing python3-pip
Your shell cached the old command list. Close and reopen the terminal, or run hash -r.
apt install asks for a password and rejects mine
You need sudo (administrator) rights on the machine. If it's a shared lab computer, check with whoever manages it — your account may need to be added to the sudoers group.
"jupyter: command not found"
Almost always means venv isn't active. Run source venv/bin/activate first, then try jupyter notebook again. If it still fails, re-run pip install notebook from inside the active environment.
Browser doesn't open automatically / "no browser found"
Copy the http://localhost:8888/tree?token=... URL printed in the terminal and paste it into any browser manually.
A cell shows ModuleNotFoundError for a package you just installed
The notebook's kernel is usually a different Python than the one you installed into. Check Kernel → Change kernel and make sure it points at ~/aiml-lab/venv, or fully quit and relaunch jupyter notebook after activating venv.

Q3

Temperature Conversion

Write a Python program to convert temperature from Celsius to Fahrenheit.
Use: F = (C × 9/5) + 32
Also modify the program to convert Fahrenheit back to Celsius.
q3_temperature.py
celsius = float(input("Enter temperature in Celsius: "))
fahrenheit = (celsius * 9 / 5) + 32
print(f"{celsius}°C = {fahrenheit}°F")
 
# Convert Fahrenheit back to Celsius
fahrenheit_in = float(input("Enter temperature in Fahrenheit: "))
celsius_out = (fahrenheit_in - 32) * 5 / 9
print(f"{fahrenheit_in}°F = {celsius_out}°C")
Sample run
output
$ python3 q3_temperature.py

37.0°C = 98.6°F
Enter temperature in Fahrenheit: 98.6
98.6°F = 37.0°C
Q4

Area and Perimeter

Write a program to accept the length and breadth of a rectangle and calculate:
  • Area
  • Perimeter
Extend the program to calculate the area of a circle after accepting its radius.
q4_area_perimeter.py
length = float(input("Enter length of rectangle: "))
breadth = float(input("Enter breadth of rectangle: "))
 
area = length * breadth
perimeter = 2 * (length + breadth)
 
print(f"Area of rectangle : {area}")
print(f"Perimeter of rectangle : {perimeter}")
 
# Extend: area of a circle
radius = float(input("Enter radius of circle: "))
pi = 3.14159
circle_area = pi * radius ** 2
print(f"Area of circle : {circle_area}")

Q5

Simple Interest

Write a Python program to calculate simple interest.
Use: SI = (P × R × T) / 100
where P = Principal amount, R = Rate of interest, T = Time. Display both the simple interest and total amount.
q5_simple_interest.py
principal = float(input("Enter principal amount: "))
rate = float(input("Enter rate of interest: "))
time = float(input("Enter time (in years): "))
 
simple_interest = (principal * rate * time) / 100
total_amount = principal + simple_interest
 
print(f"Simple Interest : {simple_interest}")
print(f"Total Amount : {total_amount}")
Sample run
output
$ python3 q5_simple_interest.py
Enter principal amount: 10000
Enter rate of interest: 5
Enter time (in years): 2
Simple Interest : 1000.0
Total Amount : 11000.0
